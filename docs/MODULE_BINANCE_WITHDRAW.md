# 💰 Модуль Binance Withdraw

## 📖 Описание

Модуль для автоматического вывода криптовалют с биржи Binance. Поддерживает множественные сети, многопоточность, прогресс-бары и детальное логирование операций.

## 🎯 Основные функции

### `binance_request(endpoint, method, params)`

- Универсальная функция для API запросов
- Автоматическая подпись HMAC-SHA256
- Обработка ошибок и таймаутов

### `get_account_balances()`

- Получение всех балансов аккаунта
- Фильтрация положительных балансов
- Форматированный вывод данных

### `pick_token_to_withdraw(balances)`

- Интерактивный выбор токена для вывода
- Отображение доступных балансов
- Удобный пользовательский интерфейс

### `pick_chain(token)`

- Выбор сети для вывода токена
- Проверка доступности вывода
- Поддержка множественных сетей

### `calculate_withdraw_amount(token, balance)`

- Расчет суммы для вывода
- Поддержка USDT эквивалента
- Валидация достаточности средств

### `process_withdraw_batch()`

- Многопоточная обработка выводов
- Прогресс-бары для отслеживания
- База данных для отслеживания статуса

### `BeautifulProgressBar`

- Красивые прогресс-бары с ETA
- Отображение скорости выполнения
- Цветовая индикация статуса

## ⚙️ Настройки API

```python
# config/cex_settings.py
binance_api_key = "your_api_key"
secret_key = "your_secret_key"
```

## 🔧 Настройки вывода

```python
# config/config.py
TYPE_WITHDRAW = 0              # 0 - нативные токены, 1 - USDT эквивалент
VALUES_TO_WITHDRAW = [5, 10]   # Диапазон суммы вывода
WAIT_FOR_BALANCE = True        # Ждать поступления на кошелек
NUM_THREADS = 5                # Количество потоков
SLEEP_BETWEEN_ACTIONS = 3      # Пауза между операциями
```

## 📂 Входные данные

- **Файл**: `data/walletss.txt`
- **Формат**: адреса кошельков (по одному на строку)
- **Пример**:

```text
0x742d35Cc6634C0532925a3b8D6a98E8f9C1D68B1
0x8ba1f109551bD432803012645Hac136c5d66d8
```

## 📊 Результаты и логи

- **База данных**: SQLite для отслеживания статуса
- **Логи ошибок**: `log/binance_withdraw_errors.log`
- **Полные логи**: `log/binance_withdraw_full.log`
- **Результаты**: CSV файлы с результатами выводов

### Схема БД

```sql
CREATE TABLE withdrawals (
    id INTEGER PRIMARY KEY,
    wallet_address TEXT,
    token TEXT,
    amount REAL,
    network TEXT,
    tx_id TEXT,
    status TEXT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

## 🛠️ Диагностика ошибок

### Типичные ошибки

1. **Неверные API ключи**
   ```
   Error: Invalid API key
   Solution: Проверить ключи в config/cex_settings.py
   ```

2. **Недостаточные права**
   ```
   Error: Permission denied for withdrawal
   Solution: Включить права на вывод в API настройках
   ```

3. **Недостаточный баланс**
   ```
   Error: Insufficient balance
   Solution: Пополнить баланс или уменьшить сумму
   ```

4. **Сетевые ошибки**
   ```
   Error: Network timeout
   Solution: Проверить интернет соединение
   ```
