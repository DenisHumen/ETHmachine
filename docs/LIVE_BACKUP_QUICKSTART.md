# 🚀 Live Backup Sync - Быстрый старт

## За 3 минуты до работающей системы

### Шаг 1: Установка (30 секунд)

```bash
pip install cryptography==41.0.7
```

### Шаг 2: Настройка (1 минута)

Откройте `config/config.py`:

```python
# Включите SFTP бэкап
SFTP_SERVER_INTO_BACKUP_ENABLE = True

# Включите live синхронизацию
SFTP_LIVE_SYNC_ENABLE = True

# Настройте SFTP сервер
SFTP_SERVER_INTO_BACKUP = {
    'host': 'ваш-сервер.com',
    'port': 22,
    'username': 'ваш_логин',
    'password': 'ваш_пароль',
    'remote_path': '/backups',
    
    # Уникальный ID для этой копии проекта
    'identificator': 'main',  # Или: 'laptop', 'work', 'home'
    
    # Пароль шифрования (или оставьте пустым для интерактивного ввода)
    'password_encryption': 'мой_секретный_пароль'
}
```

### Шаг 3: Запуск (30 секунд)

```bash
python main.py
```

Вы увидите:
```
✅ Конфигурация проверена успешно!
🔄 Live синхронизация бекапов запущена
```

**Готово!** 🎉 Теперь все изменения автоматически синхронизируются каждые 60 секунд.

## 🔄 Синхронизация на другом устройстве

### На втором компьютере:

1. Скопируйте проект (без папок `data/`, `db/`, `backups/`)
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте SFTP в `config.py` (тот же `identificator`!)
4. Запустите: `python main.py`
5. Выберите: `📦 Управление бэкапами` → `📥 Восстановить из Live Backup`

Все ваши данные восстановятся за пару секунд! ✨

## 🔐 Безопасность

✅ **Шифрование:** Все бекапы шифруются паролем (Fernet)  
✅ **Salt:** Уникальный для каждого backup  
✅ **Iterations:** 100,000 (защита от brute-force)  
⚠️ **Важно:** Если забудете пароль - backup не расшифровать!

## 📊 Что происходит автоматически

```
Запуск программы
    ↓
Старт live мониторинга
    ↓
Каждые 60 секунд:
    ├─ Проверка изменений (MD5 hash)
    ├─ Если изменений нет → ждём
    └─ Если есть изменения:
        ├─ Создание архива
        ├─ Шифрование паролем
        ├─ Удаление старого backup на сервере
        └─ Загрузка нового
```

**Результат:** На сервере всегда актуальная зашифрованная копия! ☁️

## ❓ FAQ

**Q: Когда создается backup?**  
A: Только при изменениях (проверка каждые 60 сек). Нет изменений = нет лишних загрузок.

**Q: Можно работать оффлайн?**  
A: Да! Программа работает, синхронизация просто будет неудачной (ошибка в логах).

**Q: Что если два человека редактируют одновременно?**  
A: Последний загруженный backup перезапишет предыдущий. Система не для командной работы.

**Q: Сколько места занимает?**  
A: Зависит от размера проекта. Обычно 1-50 MB. Только одна версия на сервере!

**Q: Можно отключить автосинхронизацию?**  
A: Да, в меню: `🔄 Live синхронизация: ✅ Активна` → выключить

## 🆘 Проблемы?

1. **Не запускается:** Проверьте `pip install cryptography`
2. **Не загружается:** Тест SFTP в меню бэкапов
3. **Неверный пароль:** Убедитесь что используете тот же пароль
4. **Логи:** Смотрите в консоль для диагностики
