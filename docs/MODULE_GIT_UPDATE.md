## Сценарии использования

### Сценарий 1: Нет локальных изменений
```
1. Пользователь выбирает "Да, обновить"
2. Система выполняет git pull
3. Обновление завершается успешно
4. Скрипт перезапускается
```

### Сценарий 2: Есть локальные изменения (проактивная проверка)
```
1. Пользователь выбирает "Да, обновить"
2. Система обнаруживает локальные изменения
3. Появляется диалог:
   ⚠️ Обнаружены локальные изменения в файлах!
   💾 Сохранить локальные изменения в git stash перед обновлением?
   
   Варианты:
   - ❌ Нет, отменить обновление
   - 💾 Да, сохранить изменения и обновить
   
4a. Если выбрано "Нет":
    - Обновление отменяется
    - Изменения остаются нетронутыми
    
4b. Если выбрано "Да":
    - Выполняется git stash
    - Выполняется git pull
    - Обновление завершается
    - Выводится информация о восстановлении: git stash pop
```

### Сценарий 3: Ошибка при обновлении (конфликты)
```
1. Пользователь выбирает "Да, обновить"
2. git pull выдает ошибку (конфликт с локальными файлами)
3. Система обнаруживает ключевые слова ошибки:
   - "would be overwritten"
   - "local changes"
   
4. Появляется диалог:
   ⚠️ Обнаружены конфликты с локальными изменениями.
   💾 Попробовать сохранить изменения через git stash и повторить?
   
   Варианты:
   - ❌ Нет, отменить
   - 💾 Да, сохранить и повторить
   
5a. Если выбрано "Нет":
    - Обновление отменяется
    
5b. Если выбрано "Да":
    - Выполняется git stash
    - Повторная попытка git pull
    - Если успешно:
      * Обновление завершается
      * Выводится информация о восстановлении
    - Если снова ошибка:
      * Выводится сообщение об ошибке
      * Обновление отменяется
```

## Технические детали

### Git stash сообщение
Автоматически создается с меткой времени:
```
Auto stash before update 2025-10-08 15:40:23
```

### Рабочая директория
Все git команды выполняются в корне проекта:
```python
cwd=os.path.dirname(os.path.dirname(os.path.dirname(__file__)))
```

### Обработка ошибок
- Все git команды используют `subprocess.run` с `capture_output=True`
- Ошибки логируются с полным выводом команды
- Пользователь получает понятные сообщения об ошибках

## Восстановление изменений после обновления

После успешного обновления с использованием git stash, восстановите изменения:

```bash
git stash pop
```

Или просмотрите список сохраненных изменений:

```bash
git stash list
```

Восстановите конкретный stash:

```bash
git stash apply stash@{0}
```
