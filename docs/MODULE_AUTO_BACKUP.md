# 📦 Модуль Auto Backup

## 📖 Описание
Модуль автоматического создания резервных копий важных файлов и директорий проекта. Создает zip-архивы с временными метками и автоматически удаляет старые бэкапы.

## 🎯 Основные функции

### `create_backup()`
- Создает резервную копию важных директорий
- Генерирует zip-архив с временной меткой
- Логирует процесс создания бэкапа

### `list_backups()`
- Отображает список существующих бэкапов
- Показывает размер и дату создания
- Сортирует по дате создания

### `cleanup_old_backups()`
- Удаляет старые бэкапы согласно настройкам
- Оставляет указанное количество последних бэкапов

## 📂 Структура бэкапов
- **Директория**: `backups/`
- **Формат имени**: `backup_YYYYMMDD_HHMMSS.zip`
- **Содержимое**: 
  - `config/` - конфигурационные файлы
  - `data/` - пользовательские данные
  - `db/` - базы данных
  - `result/` - результаты работы

## ⚙️ Настройки в config.py
```python
MAX_BACKUPS_TO_KEEP = 3           # Максимальное количество бэкапов
DISPLAY_LIST_BACKUPS = False      # Показывать список при запуске
DIRECTORIES_TO_BACKUP = [         # Директории для бэкапа
    'data', 'db', 'result'
]
```

## 📝 Логирование
- **Файл**: `log/auto_backup.log`
- **Ротация**: 10 MB
- **Хранение**: 30 дней
- **Сжатие**: zip

## 🚀 Использование
Автоматически вызывается при запуске `main.py`
