# 💱 Модуль OKX Withdraw

## 📖 Описание
Модуль для автоматического вывода средств с биржи OKX. Поддерживает вывод криптовалют на внешние кошельки с настраиваемыми параметрами и многопоточностью.

## 🎯 Основные функции

### `okx_withdraw()`
- Главная функция запуска модуля вывода
- Интерактивное меню выбора параметров
- Управление процессом вывода

### `process_withdraw_batch()`
- Обработка группы заявок на вывод
- Многопоточное выполнение операций
- Отслеживание статуса транзакций

### `okx_api_request()`
- Выполнение запросов к OKX API
- Подпись запросов с использованием HMAC
- Обработка ошибок API

### `check_balance()`
- Проверка баланса на бирже
- Получение доступных средств для вывода
- Валидация достаточности средств

### `create_withdrawal()`
- Создание заявки на вывод
- Указание адреса получателя и суммы
- Выбор сети для вывода

## ⚙️ Настройки API
```python
# config/cex_settings.py
OKX_API_KEY = "your_api_key"
OKX_API_SECRET = "your_api_secret" 
OKX_API_PASSPHRAS = "your_passphrase"
OKX_EU_TYPE = 0  # 0 - обычный, 1 - EU аккаунт
```

## 🔧 Настройки вывода
```python
# config/modules/cfg_cex.py
TYPE_WITHDRAW = 0              # 0 - нативные токены, 1 - USDT
VALUES_TO_WITHDRAW = [5, 5]    # Диапазон суммы вывода
WAIT_FOR_BALANCE = True        # Ждать поступления на кошелек

# config/modules/cfg_base.py
NUM_THREADS = 5                # Количество потоков
```

## 📂 Входные данные
- **Файл**: `data/walletss.txt`
- **Формат**: адреса кошельков (по одному на строку)
- **Пример**:
  ```
  0x742d35Cc6634C0532925a3b8D6a98E8f9C1D68B1
  0x8ba1f109551bD432803012645Hac136c5d66d8
  ```

## 📊 Результаты и логи
- **База данных**: `db/okx_withdraw_progress.db`
- **Логи ошибок**: `log/okx_withdraw_errors.log`
- **Полные логи**: `log/okx_withdraw_full.log`
- **Результаты**: `result/okx_withdrawals.csv`

### Схема БД
```sql
CREATE TABLE withdrawals (
    id INTEGER PRIMARY KEY,
    wallet_address TEXT,
    amount REAL,
    currency TEXT,
    network TEXT,
    withdraw_id TEXT,
    status TEXT,
    created_at TIMESTAMP,
    completed_at TIMESTAMP
);
```

## 🚀 Использование
1. Настройте API ключи в `config/cex_settings.py`
2. Заполните адреса в `data/walletss.txt`
3. Запустите через меню: `🏦 CEX → 💲 OKX → 💲 Withdraw from OKX`
4. Выберите валюту и сеть
5. Укажите диапазон сумм
6. Запустите процесс
