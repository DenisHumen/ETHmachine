## 🌍 Поддерживаемые языки

### 🇷🇺 Русский (Russian)
- **Мужские имена**: 50 вариантов (Александр, Дмитрий, Максим...)
- **Женские имена**: 50 вариантов (Анастасия, Мария, Дарья...)
- **Фамилии**: 80 вариантов (Иванов, Смирнов, Кузнецов...)
- **Склонение**: Автоматическое изменение фамилий для женщин (Иванов → Иванова)
- **Макс. комбинаций**: ~8 000 уникальных

### 🇺🇦 Українська (Ukrainian)
- **Чоловічі імена**: 50 варіантів (Олександр, Дмитро, Максим...)
- **Жіночі імена**: 50 варіантів (Анастасія, Марія, Дар'я...)
- **Прізвища**: 70 варіантів (Іваненко, Коваленко, Бондаренко...)
- **Відмінювання**: Автоматична зміна прізвищ для жінок
- **Макс. комбінацій**: ~7 000 унікальних

### 🇬🇧 English
- **Male names**: 50 variants (James, John, Robert...)
- **Female names**: 50 variants (Mary, Patricia, Jennifer...)
- **Last names**: 80 variants (Smith, Johnson, Williams...)
- **Max combinations**: ~8 000 unique

## 📄 Формат вывода

### Структура файла

Имя файла: `fullnames_{язык}_{timestamp}.csv`

Пример: `fullnames_ru_20251015_143022.csv`

### Содержимое CSV

**Для Linux/macOS** (разделитель: `,`):
```csv

Александр Иванов,ru
Мария Смирнова,ru
Дмитрий Кузнецов,ru
```

**Для Windows** (разделитель: `;`):
```csv

Александр Иванов;ru
Мария Смирнова;ru
Дмитрий Кузнецов;ru
```

### Колонки

| Колонка | Тип | Описание |
|---------|-----|----------|
| `fullname` | string | Полное имя (имя + фамилия) |
| `language` | string | Код языка (`ru`, `ua`, `eng`) |

## 🔧 Особенности

### 1. Автоматическое определение разделителя

Модуль определяет операционную систему и использует соответствующий разделитель:

```python
def get_csv_delimiter():
    system = platform.system().lower()
    if system == 'windows':
        return ';'  # Точка с запятой для Windows
    else:
        return ','  # Запятая для Linux/macOS
```

**Зачем?**
- Excel в Windows по умолчанию ожидает `;`
- LibreOffice и macOS Numbers работают с `,`

### 2. Склонение фамилий (RU/UA)

Для русского и украинского языков фамилии автоматически изменяются для женщин:

**Правила склонения:**

| Окончание (М) | Окончание (Ж) | Пример |
|---------------|---------------|--------|
| -ов | -ова | Иванов → Иванова |
| -ів | -іва | Петрів → Петріва |
| -ин | -ина | Ильин → Ильина |
| -ін | -іна | Ільїн → Ільїна |
| -ий | -ая | Толстой → Толстая |
| -ій | -ая | Толстій → Толстая |

**Несклоняемые:**
- Украинские фамилии на `-енко`, `-ко` (Шевченко, Бойко)

### 3. Защита от дубликатов

Алгоритм гарантирует уникальность:

```python
generated_names = set()  # Множество для уникальности

# Автоматический расчёт максимума
max_combinations = (male_count + female_count) * last_names_count

if quantity > max_combinations:
    quantity = max_combinations  # Ограничение
```

### 4. Смешанная генерация полов

По умолчанию генерируются имена обоих полов:

```python
is_male = random.choice([True, False])  # 50/50
```

### 5. Случайное перемешивание результатов

После генерации список перемешивается для равномерного распределения:

```python
result = list(generated_names)
random.shuffle(result)  # Перемешиваем результаты
```

**Зачем?**
- Избегаем последовательностей одинаковых имён
- Более естественное распределение
- Имена разных полов равномерно перемешаны

**Было (без перемешивания):**
```csv
Brandon Peterson,eng
Brandon Reyes,eng
Brenda Cooper,eng
Brenda Green,eng
Brenda Hall,eng
```

**Стало (с перемешиванием):**
```csv
Michael Johnson,eng
Анастасия Смирнова,ru
Brandon Peterson,eng
Олена Коваленко,ua
Sarah Williams,eng
```

## 📚 API документация

### Функция `generate_unique_fullnames()`

Генерирует список уникальных имён.

```python
def generate_unique_fullnames(
    language: str, 
    quantity: int, 
    gender_mix: bool = True
) -> list:
    """
    Args:
        language: Код языка ('ru', 'ua', 'eng')
        quantity: Количество имён для генерации
        gender_mix: Генерировать оба пола (True) или только мужские (False)
    
    Returns:
        list: Перемешанный список уникальных имён
    
    Raises:
        ValueError: Если язык не поддерживается
    """
```

**Пример:**
```python
names = generate_unique_fullnames('ru', 100, gender_mix=True)
# Вернёт перемешанный список: ['Екатерина Новикова', 'Дмитрий Козлов', 'Анна Соколова', ...]
```

### Функция `save_to_csv()`

Сохраняет имена в CSV файл.

```python
def save_to_csv(
    names: list,

    """
    Args:
```

**Пример:**

## 🔍 Проверка уникальности

### Алгоритм

1. Используется `set()` для автоматической фильтрации дубликатов
2. Перед генерацией рассчитывается максимум возможных комбинаций
3. Если запрошено больше максимума, количество автоматически ограничивается
4. Защита от бесконечного цикла: `max_attempts = quantity * 100`

### Статистика комбинаций

| Язык | Имена (М) | Имена (Ж) | Фамилии | Макс. комбинаций |
|------|-----------|-----------|---------|------------------|
| RU   | 50        | 50        | 80      | 8 000            |
| UA   | 50        | 50        | 70      | 7 000            |
| ENG  | 50        | 50        | 80      | 8 000            |

**Формула:**
```
Макс. комбинаций = (Мужские + Женские) × Фамилии
```

## 🐛 Решение проблем

### Проблема: "Неподдерживаемый язык"

**Причина:** Передан неверный код языка

**Решение:**
```python
# Используйте только: 'ru', 'ua', 'eng'
names = generate_unique_fullnames('ru', 100)  # ✅ Правильно
names = generate_unique_fullnames('de', 100)  # ❌ Ошибка
```

### Проблема: Сгенерировано меньше имён чем запрошено

**Причина:** Достигнут предел уникальных комбинаций

**Решение:**
```python
# Для RU максимум ~8000
names = generate_unique_fullnames('ru', 10000)
# Вернёт ~8000 имён с предупреждением в логах
```

### Проблема: Неправильный разделитель в CSV

**Причина:** Файл создан на одной ОС, открыт на другой

**Решение:**
- В Excel: Данные → Текст по столбцам → Указать разделитель
- Или откройте в LibreOffice Calc с выбором разделителя

### Проблема: Кириллица отображается как "���"

**Причина:** Неправильная кодировка при открытии

**Решение:**
- Открывайте CSV с кодировкой UTF-8
- В Excel: Данные → Из текста → UTF-8
