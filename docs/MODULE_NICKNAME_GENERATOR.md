# Генератор никнеймов

`modules/nickname_generator.py` — генерация англоязычных ников,
похожих на настоящие, под регистрации.

**Меню:** `Tools → Генератор никнеймов`
**Точка входа:** `generate_nicknames()`

Вопросов не задаёт: всё берётся из конфига.

---

## Настройки

`config/modules/cfg_generators.py`, словарь `NICKNAME_GENERATOR`:

| Ключ | Значение по умолчанию | Что делает |
|---|---|---|
| `MIN_LENGTH` | `10` | минимальная длина результата |
| `MAX_LENGTH` | `15` | максимальная длина результата |
| `QUANTITY` | `10000` | сколько ников сгенерировать |
| `USE_SPECIAL_CHARS` | `False` | разрешить `_`, `-`, `.` внутри ника |
| `USE_NUMBERS` | `True` | включает вставку чисел из `NICE_NUMBERS` |
| `MIN_NUMBERS` / `MAX_NUMBERS` | `1` / `3` | сколько чисел вставить |
| `NICE_NUMBERS` | `[7, 13, 21, 27, 69, 77, 88, 99, 123, 777, 999]` | пул чисел для вставки |

Все эти ключи проверяются при старте программы — см.
[MODULE_CONFIG_VALIDATOR_NICKNAME.md](MODULE_CONFIG_VALIDATOR_NICKNAME.md).

## Как строится ник

1. **Основа.** С равной вероятностью — либо слоговая генерация
   (чередование согласных и гласных), либо комбинация слов по одной из
   стратегий: `prefix_suffix`, `word_word`, `syllable_word` и — только
   при `USE_NUMBERS = False` — `word_number`.
   Словари `prefixes` (`dark`, `cyber`, `frost`, …), `suffixes`
   (`master`, `dragon`, `hunter`, …) и `words` (`gamer`, `sniper`, …)
   зашиты в класс `NicknameGenerator`.
2. **Числа.** При `USE_NUMBERS = True` берётся `MIN_NUMBERS`–`MAX_NUMBERS`
   значений из `NICE_NUMBERS` и вставляется по одной из схем: `end`,
   `start`, `middle`, `mixed`.
3. **Спецсимволы.** При `USE_SPECIAL_CHARS = True` — с вероятностью 30 %
   один символ из `_ - .` вставляется внутрь (не в начало и не в конец).
4. **Регистр.** Один из пяти стилей с весами: нижний (0.5), `Capitalize`
   (0.2), верхний (0.1), `Title` (0.1), чередование (0.1).
5. **Подгонка длины.** Длиннее `MAX_LENGTH` — обрезается, короче
   `MIN_LENGTH` — добивается цифрами.

> Из-за обрезки на последнем шаге при узком диапазоне длины и большом
> `MAX_NUMBERS` часть вставленных чисел может не дожить до результата.

---

## Уникальность

Ники копятся в `set`, поэтому дубликатов не будет. Число попыток
ограничено: `QUANTITY * 10`. Если комбинаций при заданных настройках
меньше, чем `QUANTITY`, модуль вернёт меньше ников, чем просили, и не
зациклится.

---

## Результат

`result/nicknames.txt` — по одному нику на строку.

Файл **перезаписывается** при каждом запуске (`mode='w'`). Перед новым
прогоном сохраните предыдущий, если он нужен.

В консоль выводятся первые 5 ников для быстрой проверки настроек.
