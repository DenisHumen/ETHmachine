# 🎭 Генератор Никнеймов

Модуль для создания человечески выглядящих никнеймов с гибкими настройками.

## 📋 Настройки (config/modules/cfg_generators.py)

```python
NICKNAME_GENERATOR = {
    'MIN_LENGTH': 6,        # Минимальная длина никнейма
    'MAX_LENGTH': 12,       # Максимальная длина никнейма
    'USE_SPECIAL_CHARS': True,  # Использовать специальные символы (_-.)
    'QUANTITY': 10          # Количество никнеймов для генерации
}
```

### Параметры:

- **MIN_LENGTH** - минимальное количество символов в никнейме (рекомендуется 4-8)
- **MAX_LENGTH** - максимальное количество символов (рекомендуется 8-15)
- **USE_SPECIAL_CHARS** - добавляет символы `_`, `-`, `.` для более разнообразных никнеймов
- **QUANTITY** - сколько уникальных никнеймов сгенерировать за один запуск

## 🚀 Запуск

### Из главного меню:
1. Запустите `python main.py`
2. Выберите `🧰 Tools`
3. Выберите `🎭 Nickname Generator`

### Напрямую:
```bash
python -c "from modules.nickname_generator import generate_nicknames; generate_nicknames()"
```

Сгенерированные никнеймы сохраняются в файл `result/nicknames.txt`

## 🎨 Алгоритм генерации

Генератор использует несколько стратегий:

1. **Syllable Generation** - создание из слогов (согласная + гласная)
2. **Word Combination** - комбинирование популярных префиксов и суффиксов
3. **Number Addition** - добавление цифр для уникальности
4. **Style Variation** - различные стили капитализации

## 🔧 Технические особенности

- Проверка уникальности сгенерированных никнеймов
- Автоматическая подгонка под заданную длину
- Естественное звучание благодаря использованию слогов
- Поддержка различных стилей капитализации
