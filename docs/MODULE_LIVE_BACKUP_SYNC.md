# 🔄 Live Backup Синхронизация

## 📋 Описание

Модуль **Live Backup Sync** обеспечивает автоматическую синхронизацию рабочих данных на SFTP сервер с шифрованием. Позволяет работать с проектом на разных устройствах, сохраняя единую актуальную версию данных на сервере.

## ✨ Основные возможности

- 🔄 **Автоматический мониторинг изменений** - отслеживание файлов каждые 60 секунд
- 🔐 **Шифрование данных** - все бекапы шифруются паролем (Fernet + PBKDF2)
- 🎯 **Уникальный идентификатор** - поддержка нескольких независимых копий проекта
- ☁️ **Единственная версия на сервере** - всегда актуальный бекап, старые удаляются
- 📥 **Восстановление на любом устройстве** - скачать и расшифровать live backup
- 🗑️ **Удаление с подтверждением** - безопасное удаление с интерактивным диалогом

## 🔐 Шифрование

### Алгоритм

- **Метод:** Fernet (симметричное шифрование)
- **Ключ:** Генерируется из пароля через PBKDF2
- **Salt:** Уникальный для каждого бекапа
- **Iterations:** 100,000 (защита от brute-force)

### Управление паролями

**Вариант 1: Пароль в конфиге (удобно)**
```python
SFTP_SERVER_INTO_BACKUP = {
    # ...
    'password_encryption': 'my_secure_password_12345'
}
```

**Вариант 2: Интерактивный ввод (безопаснее)**
```python
SFTP_SERVER_INTO_BACKUP = {
    # ...
    'password_encryption': ''  # Оставить пустым
}
```

При создании/восстановлении будет запрошен пароль:
```
🔐 Введите пароль для шифрования:
🔐 Повторите пароль для подтверждения:
```

## 🔄 Как работает автоматическая синхронизация

### Мониторинг изменений

1. **Запуск фонового потока** при старте программы
2. **Каждые 60 секунд:**
   - Вычисляется MD5 хеш каждого файла в проекте
   - Сравнивается с предыдущим состоянием
   - Если обнаружены изменения → создается новый live backup

### Структура hash-файла

Сохраняется в `db/directory_hash.json`:

```json
{
  "config/config.py": "d41d8cd98f00b204e9800998ecf8427e",
  "main.py": "098f6bcd4621d373cade4e832627b4f6",
  "modules/backup/backup_manager.py": "5d41402abc4b2a76b9719d911017c592"
}
```

### Логика синхронизации

```python
# Псевдокод
while True:
    current_hash = calculate_directory_hash()
    
    if current_hash != saved_hash:
        logger.info("🔄 Обнаружены изменения, создаю live backup...")
        create_live_backup()
        saved_hash = current_hash
        save_hash_to_file()
    
    sleep(60)  # Ждем 60 секунд
```

## ⚠️ Важные замечания

### Безопасность

- ✅ **Используйте надежный пароль** для шифрования
- ✅ **Не храните пароль в Git** - используйте `.env` файлы
- ✅ **Разные пароли** для разных проектов
- ⚠️ **Пароль нельзя восстановить** - если забыли, backup не расшифровать

### Производительность

- 📊 MD5 хеширование быстрое (~1-2 сек для средних проектов)
- 📊 Проверка каждые 60 сек - минимальная нагрузка
- 📊 Загрузка на SFTP зависит от размера и скорости сети

### Ограничения

- ❌ Не отслеживает изменения в реальном времени (только каждые 60 сек)
- ❌ Не поддерживает конфликты при одновременном редактировании
- ❌ Один файл на сервере (нет истории версий для live backup)

## 🛠️ Технические детали

### Структура классов

```python
class EncryptionManager:
    """Управление шифрованием/расшифровкой"""
    
    def encrypt_file(self, input_file: str, output_file: str, password: str)
    def decrypt_file(self, input_file: str, output_file: str, password: str)

class LiveSyncMonitor:
    """Мониторинг изменений в файловой системе"""
    
    def calculate_directory_hash(self) -> Dict[str, str]
    def check_for_changes(self) -> bool
    def monitor_loop(self)
    def start(self)
    def stop(self)

class BackupManager:
    """Основной менеджер бэкапов с live sync"""
    
    def create_live_backup(self) -> bool
    def restore_live_backup(self) -> bool
    def delete_live_backup_with_confirmation(self)
    def check_live_backup_exists(self) -> bool
    def start_live_monitoring(self)
    def stop_live_monitoring(self)
```

### Формат зашифрованного файла

```
[16 bytes SALT] + [encrypted data]
```

- **Salt:** Случайные 16 байт для PBKDF2
- **Data:** Зашифрованный ZIP архив

## 🆘 FAQ

**Q: Как часто создается live backup?**  
A: Только при обнаружении изменений (проверка каждые 60 секунд).

**Q: Можно ли изменить интервал мониторинга?**  
A: Да, в `backup_manager.py` измените `time.sleep(60)` на нужное значение.

**Q: Что если забыл пароль шифрования?**  
A: К сожалению, backup не расшифровать. Создайте новый с новым паролем.

**Q: Можно ли использовать без SFTP?**  
A: Нет, live sync требует SFTP для синхронизации между устройствами.

**Q: Влияет ли на производительность программы?**  
A: Минимально. Мониторинг работает в отдельном daemon-потоке.

**Q: Можно ли восстановить старую версию?**  
A: Нет, live backup - только текущая версия. Для истории используйте обычные бэкапы.
