# 💰 Модуль Zora Claimer

## 📖 Описание

Модуль для автоматического клейма наград Zora Protocol Rewards на сетях **Base** и **Zora**. Поддерживает многопоточность, работу с прокси, базу данных для отслеживания прогресса и экспорт результатов в Excel.

Zora Protocol Rewards — это награды, которые накапливаются для создателей и коллекционеров на платформе Zora. Контракт `ProtocolRewards` находится по адресу `0x7777777F279eba3d3Ad8F4E708545291A6fDBA8B` (одинаковый на всех сетях).

## 🎯 Основные функции

- Проверка доступных наград на Base и Zora сетях
- Автоматический клейм с проверкой баланса газа
- Мультипоточная обработка кошельков
- База данных SQLite для отслеживания прогресса
- Экспорт результатов в Excel (XLSX)
- Ротация прокси при ошибках
- Повторные попытки при неудачах

## ⚙️ Конфигурация

Файл: `config/modules/cfg_claimer.py`

| Параметр | Описание | По умолчанию |
|---|---|---|
| `MIN_CLAIM_AMOUNT_ETH` | Минимальная сумма для клейма (ETH) | `0.0001` |
| `MIN_GAS_BALANCE_ETH` | Минимальный баланс для газа (ETH) | `0.00005` |
| `CLAIMER_USE_PROXY` | Использовать прокси | `True` |
| `CLAIMER_RANDOM_PROXY` | Случайный прокси | `True` |
| `CLAIMER_SHUFFLE_WALLETS` | Перемешивать кошельки | `True` |
| `CLAIM_TO_SELF` | Клеймить на свой адрес | `True` |
| `CLAIM_TO_ADDRESS` | Адрес для вывода (если `CLAIM_TO_SELF=False`) | `''` |

Глобальные параметры из `config/modules/cfg_base.py`:
- `NUM_THREADS` — количество потоков
- `SLEEP_BETWEEN_ACTIONS` — задержка между действиями
- `DELAY_BETWEEN_ACCOUNTS` — задержка между аккаунтами
- `RETRY_COUNT` — количество повторных попыток
- `TX_SEND_ATTEMPTS` — попытки отправки транзакции

Сети настраиваются в `CLAIMER_NETWORKS`:
```python
CLAIMER_NETWORKS = {
    'base': {
        'enabled': True,        # Включить/выключить сеть
        'rpc_urls': [...],      # RPC эндпоинты
        'chain_id': 8453,
        'explorer_tx': '...',
        'symbol': 'ETH',
        'name': 'Base',
    },
    'zora': { ... },
}
```

## 📋 Входные данные

- **Приватные ключи**: `data/private_keys.txt` — по одному ключу на строку (hex формат)
- **Прокси**: `data/proxy.csv` — формат `login:password@ip:port`

## 🚀 Использование

### Меню

В главном меню выберите **Claimer**. Доступны 3 действия:

1. **Запуск клеймера** — основная работа
2. **Очистка базы данных** — сброс всех задач
3. **Выгрузка результатов** — экспорт текущего состояния в Excel

### При запуске

- Если БД пуста — создаётся новая и запускается клейм
- Если БД есть и не завершена — предлагается продолжить или очистить
- Если БД завершена на 100% — автоматическая очистка с уведомлением

### Процесс работы

1. Загрузка приватных ключей и прокси
2. Создание задач в БД для каждого кошелька × каждая сеть
3. Для каждого кошелька:
   - Проверка `balanceOf` на контракте ProtocolRewards
   - Если баланс >= `MIN_CLAIM_AMOUNT_ETH`:
     - Проверка баланса ETH для оплаты газа
     - Проверка что газ не превышает клейм
     - Отправка транзакции `withdraw(address, 0)` (0 = забрать всё)
     - Ожидание подтверждения
   - Обновление статуса в БД
4. Вывод статистики
5. Экспорт результатов в Excel

## 📊 Результаты

Excel файл сохраняется в `result/zora_claimer_YYYYMMDD_HHMMSS.xlsx` и содержит:

| Колонка | Описание |
|---|---|
| Wallet | Адрес кошелька |
| Network | Сеть (Base/Zora) |
| Status | Статус (completed/failed/skipped) |
| Claimable ETH | Доступно для клейма |
| Claimed ETH | Заклеймлено |
| Gas Cost ETH | Стоимость газа |
| TX Hash | Хеш транзакции |
| Error | Сообщение об ошибке |

## 🗄️ База данных

Файл: `db/zora_claimer.db`

### Таблица `claim_tasks`

Хранит задачи для каждого кошелька и сети:
- Статус: `pending` → `in_progress` → `completed`/`failed`/`skipped`
- Данные о клейме, транзакции, газе
- Количество попыток и ошибки

### Таблица `claim_statistics`

Агрегированная статистика по запускам.
