# MODULE: xStocks DeFi Points

## Описание

Автоматизация фарма очков на [xStocks DeFi Points](https://defi.xstocks.fi/points).

**Возможности:**

- Регистрация EVM кошельков (эмуляция MetaMask)
- Регистрация Solana кошельков (эмуляция Phantom)
- Say GM — ежедневный клик для получения очков
- Daily Spin — ежедневный множитель
- Реферальная система с балансировкой
- Бесконечный цикл GM фарминга
- Экспорт статистики в Excel

## Подготовка

### 1. data.csv

Заполните `data/data.csv` кошельками. Необходимые поля:

- `private_key` — приватный ключ EVM
- `proxy` — http прокси (опционально, формат: `user:pass@ip:port`)
- `sol_private_key` — приватный ключ Solana (опционально, base58)
- `referral_code` — реферальный код для регистрации (опционально)

### 2. Настройки

`config/modules/cfg_xstocks.py`:

- `GM_COOLDOWN_HOURS` = 24 — кулдаун между GM
- `SHUFFLE_WALLETS` — перемешивать порядок кошельков
- `INFINITE_LOOP` — бесконечный режим
- `REFERRAL_MAX_USAGE_DIFF_PERCENT` = 50 — балансировка рефералов

## Использование

### Меню

В главном меню: **Projects** → **xStocks DeFi Points**

### Режимы

1. **Регистрация кошельков** — зарегистрировать все незарегистрированные кошельки
2. **Подключить Solana** — зарегистрировать Solana кошельки
3. **Say GM (однократно)** — один раунд GM для всех готовых кошельков
4. **GM бесконечный цикл** — основной режим фарминга (рег + sol + GM loop)
5. **Полный автомат** — регистрация + Solana + бесконечный GM
6. **Статистика** — обновить статистику всех кошельков
7. **Экспорт в Excel** — выгрузить данные в XLSX

### Бесконечный цикл GM

```
Цикл:
  1. Проверить незарегистрированные → зарегистрировать
  2. Проверить Solana → подключить
  3. Проверить готовые к GM → Say GM + Daily Spin
  4. Вычислить время до следующего GM → спать
  5. Повторить
```

## Реферальная система

- При регистрации первые кошельки создают реферальные коды
- Последующие кошельки используют коды предыдущих
- Приоритет: `referral_code` из data.csv → случайный из БД (с балансировкой)
- Балансировка: разница использований кодов не больше 50%

## База данных

Файл: `db/xstocks.db` (SQLite)

- Автоматически создаётся при первом запуске
- Сохраняет статусы регистрации, историю GM, реферальные коды

## Прокси

- 1:1 привязка прокси к кошельку
- Автоматическая ротация при ошибках
- Поддержка HTTP

## Зависимости

- `aiohttp`, `aiohttp-socks` — HTTP клиент
- `eth-account` — подписание EVM
- `solders`, `base58` — подписание Solana
- `openpyxl` — экспорт Excel
- `fake-useragent` — рандомизация User-Agent
