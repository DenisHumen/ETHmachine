# 💼 Модуль OKX Subaccount

## 📖 Описание

Модуль для управления субаккаунтами на бирже OKX. Обеспечивает автоматический сбор средств с субаккаунтов на основной аккаунт, мониторинг балансов и управление переводами.

## 🎯 Основные функции

### `get_subaccounts_list()`

- Получение списка всех субаккаунтов
- Отображение информации о статусе
- Подсчет количества активных субаккаунтов

### `get_subaccount_balance(subacct_name)`

- Проверка баланса конкретного субаккаунта
- Получение данных по всем валютам
- Фильтрация активных балансов

### `get_main_account_balance()`

- Мониторинг баланса основного аккаунта
- Проверка доступных средств
- Отслеживание изменений

### `transfer_from_subaccount_to_main()`

- Перевод средств с субаккаунта на основной
- Автоматическая конвертация типов
- Валидация операций

### `collect_all_subaccount_balances()`

- Массовый сбор средств со всех субаккаунтов
- Пакетная обработка переводов
- Статистика выполненных операций

## ⚙️ Настройки API

```python
# config/cex_settings.py
OKX_API_KEY = "your_api_key"
OKX_API_SECRET = "your_api_secret" 
OKX_API_PASSPHRAS = "your_passphrase"
OKX_EU_TYPE = 0  # 0 - обычный, 1 - EU аккаунт
```

## 🔧 Параметры подключения

```python
class OKXClient:
    def __init__(self, api_key, secret_key, passphrase, sandbox=False):
        self.base_url = "https://www.okx.com"  # Production URL
        self.sandbox = sandbox                 # Тестовое окружение
```

## 📊 Результаты и логи

- **Логи ошибок**: `log/okx_subaccount_errors.log`
- **Полные логи**: `log/okx_subaccount_full.log`
- **Ротация**: 10 MB для ошибок, 50 MB для полных логов
- **Хранение**: 7 дней для ошибок, 3 дня для полных логов

## 🔄 Алгоритм работы

1. **Получение списка субаккаунтов**
   - Запрос к API `/api/v5/users/subaccount/list`
   - Валидация ответа
   - Подсчет активных аккаунтов

2. **Проверка балансов**
   - Перебор всех субаккаунтов
   - Запрос баланса для каждого
   - Фильтрация ненулевых балансов

3. **Выполнение переводов**
   - Создание заявок на перевод
   - Мониторинг статуса
   - Обработка ошибок

4. **Статистика**
   - Подсчет успешных операций
   - Учет неудачных попыток
   - Итоговый отчет

- Стейблкоины (USDT, USDC, BUSD)

## 🚀 Использование

1. **Настройка API ключей**
   ```python
   client = OKXClient(api_key, secret_key, passphrase)
   ```

2. **Проверка субаккаунтов**
   ```python
   subaccounts = client.get_subaccounts_list()
   ```

3. **Сбор средств**
   ```python
   client.collect_all_subaccount_balances()
   ```

4. **Мониторинг результатов**
   - Просмотр логов
   - Проверка статистики
   - Анализ ошибок

## 🛠️ Диагностика ошибок

### Типичные ошибки

1. **Неверные API ключи**
   - Проверить настройки в config
   - Убедиться в правильности passphrase

2. **Недостаточно прав**
   - Включить права на субаккаунты
   - Проверить разрешения API

3. **Сетевые ошибки**
   - Проверить интернет-соединение
   - Убедиться в доступности API

4. **Лимиты API**
   - Увеличить паузы между запросами
   - Мониторить rate limits
