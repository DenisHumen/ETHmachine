# 💼 Модуль ETH Wallet Generator

## 📖 Описание
Модуль для генерации Ethereum кошельков. Создает криптографически безопасные мнемонические фразы, приватные ключи и адреса кошельков.

## 🎯 Основные функции

### `eth_generate_wallets(count)`
- Генерирует указанное количество кошельков
- Создает мнемонические фразы (12 слов)
- Выводит приватные ключи и адреса
- Сохраняет результаты в CSV

### Класс `Wallet`
- `generate_mnemonic()` - создание мнемонической фразы
- `mnemonic_to_seed()` - преобразование в seed
- `seed_to_private_key()` - получение приватного ключа
- `private_key_to_address()` - генерация адреса

### Класс `PublicKey`
- Работа с эллиптическими кривыми
- Генерация публичного ключа
- Создание Ethereum адреса

## 🔐 Криптографические особенности

### Стандарты
- **BIP39**: мнемонические фразы
- **BIP32**: иерархические детерминированные кошельки
- **BIP44**: путь деривации для Ethereum
- **SECP256k1**: эллиптическая кривая

### Параметры
```python
BIP39_PBKDF2_ROUNDS = 2048
ETH_DERIVATION_PATH = "m/44'/60'/0'/0"
BIP32_SEED_MODIFIER = b'Bitcoin seed'
```

## 📂 Результаты
- **Файл**: `result/result.csv`
- **Формат**: `address,balance,network`
- **Пример**:
  ```csv
  address,balance,network
  0x742d35Cc6634C0532925a3b8D6a98E8f9C1D68B1,,ethereum
  ```

## 🎮 Использование через меню
1. Запустите `main.py`
2. Выберите `🪙 Generate Wallets`
3. Укажите количество кошельков
4. Выберите `💲 ETH → 💲 Normal`

## 📊 Поддерживаемые количества
- 1, 10, 100, 1000, 5000, 10000
- Ручной ввод любого количества

## 🔒 Безопасность
- Криптографически стойкая генерация
- Использование системного ГСЧ
- Соответствие стандартам BIP
- Проверка целостности ключей

## ⚡ Производительность
- Скорость: ~1000-5000 кошельков/секунду
- Память: оптимизировано для больших объемов
- CPU: использует один поток (можно распараллелить)

## 🛠️ Зависимости
- `mnemonic` - генерация BIP39 фраз
- `ecdsa` - эллиптические кривые
- `eth_utils` - Ethereum утилиты
- `colorama` - цветной вывод
