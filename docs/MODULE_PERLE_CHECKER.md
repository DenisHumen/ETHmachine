# 📊 Модуль Perle Eligibility Checker

## 📖 Описание

Модуль для массовой проверки элигибельности SOL кошельков на Perle airdrop (https://register.perle.xyz). Эмулирует подключение кошелька Phantom через браузер. Поддерживает мультипоточность, работу с прокси, автоматические повторы при ошибках, базу данных для отслеживания прогресса и экспорт результатов в Excel.

Perle — проект на Solana, проверяющий элигибельность кошельков для раздачи токенов PRL. Модуль автоматизирует шаг "Check Eligibility" из регистрационного флоу сайта.

## 🎯 Основные функции

- Проверка элигибельности SOL кошельков через API register.perle.xyz
- Эмуляция Phantom wallet — браузерные заголовки (Origin, Referer, Sec-Fetch)
- Мультипоточная обработка кошельков (настраивается через `NUM_THREADS`)
- Автоматические повторы при ошибках (настраивается через `RETRY_COUNT`)
- Задержки между запросами и аккаунтами из конфига
- База данных SQLite для отслеживания прогресса (можно продолжить после остановки)
- Экспорт результатов в Excel (XLSX) с цветовым выделением
- Поддержка прокси из data.csv

## ⚙️ Конфигурация

Глобальные параметры из `config/modules/cfg_base.py`:

| Параметр | Описание | По умолчанию |
|---|---|---|
| `NUM_THREADS` | Количество потоков для параллельной проверки | `10` |
| `SLEEP_BETWEEN_ACTIONS` | Задержка при повторах (сек) | `[2, 4]` |
| `DELAY_BETWEEN_ACCOUNTS` | Задержка между стартом аккаунтов (сек) | `[1, 3]` |
| `RETRY_COUNT` | Количество повторных попыток при ошибке | `2` |

## 📋 Подготовка данных

### data/data.csv

В файле `data/data.csv` должны быть заполнены поля:

| Поле | Обязательно | Описание |
|---|---|---|
| `sol_private_key` | ✅ Да | Приватный ключ SOL кошелька (base58) |
| `proxy` | ❌ Нет | Прокси в формате `login:pass@ip:port` |

Пример:
```csv
private_key,proxy,reserve_proxy,wallet_address,mnemonic,sol_address,sol_private_key,discord_token,email,email_password,email_imap
,6CDVPIE3:0SPRBC9Y@156.255.59.15:40024,,,,,Cw6pjC2EbLB5t9...XTtVu9,,,,
```

Модуль автоматически получает публичный SOL адрес из приватного ключа.

## 🚀 Использование

### Через главное меню

1. Запустите `python main.py`
2. Выберите `📊 Check project stats`
3. Выберите `📊 Perle`
4. Выберите действие:
   - **▶️ Запуск чекера** — запустить проверку элигибельности
   - **🗑️ Очистка базы данных** — сбросить все задачи
   - **📊 Выгрузка результатов** — экспорт в Excel

### Меню чекера

```
Perle Eligibility Checker - выберите действие:
  ▶️  Запуск чекера                   Проверка элигибельности SOL кошельков
  🗑️  Очистка базы данных             Сброс всех задач
  📊 Выгрузка результатов             Экспорт в Excel
  🔙 Назад
```

### Логика работы

1. Загрузка SOL приватных ключей и прокси из `data/data.csv`
2. Создание/обновление задач в БД (пропускает уже проверенные)
3. Мультипоточная проверка элигибельности через API
4. При ошибке — автоматический повтор с задержкой (до `RETRY_COUNT` раз)
5. Вывод статистики и автоэкспорт в Excel

### Продолжение работы

Если процесс был прерван:
- При повторном запуске модуль определяет уже проверенные кошельки через БД
- Проверяет только новые/неуспешные задачи
- Если все проверены на 100% — БД очищается автоматически

## 🔒 Phantom-эмуляция

Модуль эмулирует подключение кошелька Phantom через браузер:
- Browser-like User-Agent (Chrome/Firefox/Safari)
- `Origin: https://register.perle.xyz`
- `Referer: https://register.perle.xyz/flow`
- `Sec-Fetch-*` заголовки (same-origin, cors)
- Рандомизация User-Agent для каждого запроса

Сайт видит запрос как обычное подключение кошелька через веб-интерфейс.

## 🗄️ База данных

SQLite файл: `db/perle_checker.db`

Таблица `check_tasks`:

| Поле | Тип | Описание |
|---|---|---|
| sol_address | TEXT | Публичный адрес SOL |
| status | TEXT | pending / completed / failed |
| eligible | INTEGER | 0 или 1 |
| total | TEXT | Сумма аллокации |
| details | TEXT | JSON с деталями |
| error_message | TEXT | Текст ошибки |
| attempts | INTEGER | Количество попыток |
| created_at | TIMESTAMP | Время создания |
| completed_at | TIMESTAMP | Время завершения |
