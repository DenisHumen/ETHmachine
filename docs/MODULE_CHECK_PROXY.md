# 🌐 Модуль Check Proxy

## 📖 Описание
Модуль для проверки работоспособности прокси-серверов. Тестирует HTTP/HTTPS прокси, проверяет скорость подключения и анонимность.

## 🎯 Основные функции

### `check_proxy_menu()`
- Интерактивное меню для выбора типа проверки
- Варианты: быстрая проверка, полная проверка, анонимность

### `load_proxies()`
- Загружает прокси из файла `data/proxy.csv`
- Формат: `login:password@ip:port`
- Валидирует формат прокси

### `check_proxy_with_requests()`
- Проверяет прокси через HTTP запросы
- Измеряет время ответа
- Определяет тип прокси (HTTP/HTTPS)

### `check_proxy_anonymity()`
- Проверяет уровень анонимности прокси
- Определяет: transparent, anonymous, elite
- Тестирует утечку реального IP

### `check_proxy_with_web3()`
- Проверяет прокси для работы с Web3
- Тестирует подключение к Ethereum RPC
- Проверяет совместимость с блокчейн запросами

## 📂 Входные данные
- **Файл**: `data/proxy.csv`
- **Формат**: `login:password@ip:port` (построчно)
- **Пример**:
  ```
  user1:pass1@192.168.1.1:8080
  user2:pass2@10.0.0.1:3128
  ```

## 📊 Результаты
- **Директория**: `result/proxy/`
- **Файлы**:
  - `working_proxies_YYYYMMDD_HHMMSS.csv`
  - `failed_proxies_YYYYMMDD_HHMMSS.csv`
  - `proxy_stats_YYYYMMDD_HHMMSS.json`

### Формат результатов
```csv
proxy,status,response_time,anonymity_level,country,tested_at
user:pass@ip:port,WORKING,1.25,elite,US,2025-09-12 14:30:15
```

## ⚙️ Настройки
```python
NUM_THREADS = 100        # Количество потоков
RETRY_COUNT = 5          # Количество попыток
```

## 🔍 Типы проверок

### Быстрая проверка
- Базовое HTTP подключение
- Время ответа
- Статус доступности

### Полная проверка
- HTTP/HTTPS совместимость
- Проверка анонимности
- Определение местоположения
- Тест скорости загрузки

### Web3 проверка
- Совместимость с Ethereum RPC
- Проверка блокировок блокчейн трафика
- Тест подключения к различным сетям

## 📝 Логирование
- **Файл**: `log/proxy_checker_YYYYMMDD_HHMMSS.log`
- **Уровень**: DEBUG
- **Ротация**: 10 MB
- **Хранение**: 7 дней

## 🚀 Использование
1. Заполните `data/proxy.csv`
2. Запустите через главное меню: `🧰 Miscellaneous → 🗂️ Check Proxy`
3. Выберите тип проверки
4. Получите результаты в `result/proxy/`

## 📈 Метрики производительности
- Скорость проверки: ~50-200 прокси/минуту
- Поддерживаемые протоколы: HTTP, HTTPS, SOCKS4, SOCKS5
- Таймаут подключения: настраиваемый
- Многопоточность: до 100 потоков одновременно
