# 🐦 Twitter Task - Автоматизация Twitter

Простое руководство для автоматизации задач в Twitter (лайки, ретвиты, подписки, твиты, комментарии).

---

## � Поддерживаемые типы задач

| Тип | Что делает | Value |
|-----|------------|-------|
| `like` | ❤️ Лайк твита | Число повторений |
| `retweet` | 🔁 Ретвит | Число повторений |
| `follow` | 👤 Подписка | Число повторений |
| `unfollow` | 👋 Отписка | Число повторений |
| `tweet` | ✍️ Публикация твита | Текст твита |
| `comment` | 💬 Комментарий | Текст комментария |

---

## 📖 Как это работает?

Модуль автоматически выполняет действия от имени ваших Twitter аккаунтов.
Вы создаете список задач, и программа выполняет их со всех ваших аккаунтов.

---

## 🚀 Быстрый старт (3 простых шага)

### Шаг 1: Получите ключ от Twitter аккаунта

1. Откройте **x.com** в браузере (Chrome, Firefox, Edge)
2. **Войдите** в свой Twitter аккаунт
3. Нажмите клавишу **F12** на клавиатуре
4. Откроется панель - перейдите на вкладку **Application** (или **Приложение**)
5. Слева найдите **Cookies** → нажмите на **https://x.com**
6. Найдите строку с именем **auth_token**
7. Дважды кликните по её значению и **скопируйте** (Ctrl+C)

> 💡 **Это выглядит примерно так:** `a1b2c3d4e5f6...` (длинный набор букв и цифр)

---

### Шаг 2: Добавьте аккаунты

Откройте файл: **`data/twitter/twitters.csv`**

Вставьте туда свои аккаунты в таком формате:

```csv
nickname,auth_token,ct0,proxy
мой_аккаунт,сюда_вставьте_auth_token,,
второй_аккаунт,другой_auth_token,,
```

**Объяснение:**
- `nickname` - любое название (опционально, можно оставить пустым - будет `account_1`, `account_2` и т.д.)
- `auth_token` - ключ который вы скопировали на Шаге 1 (**обязательно**)
- `ct0` - оставьте пустым (две запятые `,,`)
- `proxy` - если нужен прокси, пишите так: `login:password@1.2.3.4:8080`, если нет - оставьте пустым

**Пример с 2 аккаунтами:**
```csv
nickname,auth_token,ct0,proxy
main,abc123def456ghi789jkl012mno345pqr678,,
,xyz987wvu654tsr321qpo098nml765kji432,,login:pass@proxy.com:8080
```

> 💡 **Подсказка:** Колонку `nickname` можно оставить пустой - система автоматически назовёт аккаунты `account_1`, `account_2` и т.д.

---

### Шаг 3: Создайте задачи

Откройте файл: **`data/twitter/twitter_task.csv`**

Добавьте задачи в таком формате:

```csv
link,type,value
```

**Все поддерживаемые типы задач:**

#### ❤️ Лайк (like)
Поставить лайк на твит

```csv
https://x.com/username/status/1234567890,like,3
```
- `link` - ссылка на твит
- `type` - `like`
- `value` - сколько раз лайкнуть (число)

---

#### 🔁 Ретвит (retweet)
Сделать ретвит твита

```csv
https://x.com/username/status/1234567890,retweet,1
```
- `link` - ссылка на твит
- `type` - `retweet`
- `value` - сколько раз ретвитнуть (число)

---

#### 👤 Подписка (follow)
Подписаться на пользователя

```csv
elonmusk,follow,2
```
- `link` - имя пользователя (можно `username`, `@username` или полную ссылку)
- `type` - `follow`
- `value` - сколько раз подписаться (число)

---

#### 👋 Отписка (unfollow)
Отписаться от пользователя

```csv
some_user,unfollow,1
```
- `link` - имя пользователя (можно `username`, `@username` или полную ссылку)
- `type` - `unfollow`
- `value` - сколько раз отписаться (число)

---

#### ✍️ Твит (tweet)
Опубликовать твит

```csv
,tweet,Привет Twitter! Это мой первый автоматический твит 🚀
```
- `link` - оставьте пустым
- `type` - `tweet`
- `value` - текст твита для публикации

---

#### 💬 Комментарий (comment)
Оставить комментарий под твитом

```csv
https://x.com/username/status/1234567890,comment,Отличный пост! 👍
```
- `link` - ссылка на твит
- `type` - `comment`
- `value` - текст комментария

---

### Полный пример задач:

```csv
link,type,value
https://x.com/elonmusk/status/1234567890,like,2
https://x.com/elonmusk/status/1234567890,retweet,1
vitalikbuterin,follow,1
spam_account,unfollow,1
,tweet,Изучаю крипту каждый день! #crypto #learning 📚
https://x.com/news/status/9876543210,comment,Интересная новость!
```

**Что произойдет:**
Каждый аккаунт из `twitters.csv`:
1. Поставит 2 лайка на твит Илона Маска
2. Сделает 1 ретвит этого твита
3. Подпишется на Виталика Бутерина 1 раз
4. Отпишется от spam_account 1 раз
5. Опубликует твит с указанным текстом
6. Оставит комментарий под новостным твитом

## ▶️ Как запустить?

1. Убедитесь что заполнили `twitters.csv` и `twitter_task.csv`
2. Запустите программу: `python main.py`
3. В меню выберите: **🐦 Twitter** → **🐦 Twitter Task**
4. Программа начнет выполнять задачи
5. Результаты сохранятся в папке `result/twitter/`

---

## ⚙️ Настройки (опционально)

Откройте файл: **`config/config.py`**

Найдите секцию `TWITTER TASK RUNNER`:

```python
TWITTER_TASK_SSL_VERIFICATION = True  # Проверка SSL (оставьте True)
TWITTER_TASK_DELAY_BETWEEN_TASKS = 5  # Пауза между задачами (секунды)
TWITTER_TASK_DELAY_BETWEEN_ACCOUNTS = 3  # Пауза между аккаунтами (секунды)
```

**Что можно изменить:**
- Увеличьте паузы если Twitter блокирует за частые действия
- Уменьшите паузы если хотите быстрее (не рекомендуется)

## 📊 Как работают повторения и распределение?

### Логика распределения аккаунтов:

**Каждое повторение задачи выполняется РАЗНЫМ аккаунтом!**

Пример: У вас 5 аккаунтов и 2 задачи:
- Задача 1: LIKE с 2 повторениями
- Задача 2: FOLLOW с 2 повторениями

Распределение:
```
Задача 1 (LIKE):
  Повтор 1 → account_1
  Повтор 2 → account_2

Задача 2 (FOLLOW):
  Повтор 1 → account_3
  Повтор 2 → account_4
```

**Итого:** Использовано 4 аккаунта из 5 доступных.

### Параметр `value`:

**Для действий (число повторений):**
- **like** - сколько раз лайкнуть (разными аккаунтами)
- **retweet** - сколько раз ретвитнуть (разными аккаунтами)
- **follow** - сколько раз подписаться (разными аккаунтами)
- **unfollow** - сколько раз отписаться (разными аккаунтами)

**Для контента (текст):**
- **tweet** - текст для публикации
- **comment** - текст комментария

**Пример:**
```csv
https://x.com/user/status/123,like,5
```

Если у вас **2 аккаунта** в `twitters.csv`:
- Аккаунт 1 поставит лайк 5 раз
- Аккаунт 2 поставит лайк 5 раз
- **Итого: 10 лайков** (2 аккаунта × 5 повторений)

## ❓ Частые вопросы

### Как добавить прокси?
В файле `twitters.csv` в колонке `proxy` напишите:
```
login:password@ip:port
```
Пример: `user123:pass456@192.168.1.1:8080`

### Сколько аккаунтов можно добавить?
Без ограничений. Но чем больше аккаунтов, тем дольше выполнение.

### Можно ли использовать без прокси?
Да! Просто оставьте колонку `proxy` пустой.

### Что если Twitter заблокирует аккаунт?
- Используйте разумные задержки (5+ секунд)
- Не делайте слишком много действий за раз
- Используйте прокси для множественных аккаунтов
- Начните с тестового аккаунта

### Как получить ссылку на твит?
Откройте твит в браузере и скопируйте URL из адресной строки.

## ⚠️ Важные правила

1. **Не делитесь auth_token** - это полный доступ к аккаунту
2. **Начните с тестов** - попробуйте на 1-2 аккаунтах сначала
3. **Используйте задержки** - Twitter может заблокировать за спам
4. **Проверяйте результаты** - смотрите файлы в `result/twitter/`
5. **Храните резервные копии** - файлы `twitters.csv` и `twitter_task.csv`

---

## 🛠 Что делать при ошибках?

### "Не удалось инициализировать аккаунт"
→ Проверьте правильность `auth_token` (возможно устарел)
→ Зайдите в Twitter и получите новый токен

### "Ошибка лайка/ретвита"
→ Проверьте что ссылка правильная
→ Убедитесь что твит существует и доступен

### "Ошибка подписки"
→ Проверьте что пользователь существует
→ Возможно аккаунт приватный

### "Прокси не работает"
→ Проверьте формат: `login:password@ip:port`
→ Убедитесь что прокси онлайн
