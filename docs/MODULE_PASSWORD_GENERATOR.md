# Генератор паролей

`modules/password_generator.py` — генерация паролей случайной длины по
правилам из конфига.

**Меню:** `Tools → Генератор паролей`
**Точка входа:** `password_generator_menu()`

Интерактивных вопросов модуль не задаёт: запустил — и он отработал по
настройкам.

---

## Настройки

`config/modules/cfg_password.py`:

| Параметр | Значение по умолчанию | Что делает |
|---|---|---|
| `PASSWORD_LENGTH` | `[12, 16]` | диапазон длины; на каждый пароль берётся случайное значение из него |
| `USE_SPECIAL_CHARACTERS` | `True` | добавляет `string.punctuation` в алфавит |
| `EXCLUDE_CHARACTERS` | `['0', 'O', 'I', 'l']` | символы, выкинутые из алфавита |
| `USE_OF_SYMBOLS_IS_MANDATORY` | `['!']` | символы, которые обязаны попасть в каждый пароль |
| `COUNT_GENERATED_PASSWORDS` | `10` | сколько паролей сгенерировать за запуск |

Базовый алфавит — `string.ascii_letters + string.digits`, то есть
`A-Za-z0-9`; спецсимволы добавляются только при
`USE_SPECIAL_CHARACTERS = True`. Затем из алфавита вычитаются
`EXCLUDE_CHARACTERS`. Если после вычитания алфавит пуст, генерация падает
с `ValueError: Charset is empty after exclusions.`

---

## Как собирается пароль

1. В пароль сразу кладутся все элементы `USE_OF_SYMBOLS_IS_MANDATORY`.
2. Остаток добирается случайными символами из алфавита до выбранной длины.
3. Список перемешивается (`random.shuffle`) и обрезается до длины.

Из шага 3 следует ограничение: если `USE_OF_SYMBOLS_IS_MANDATORY`
длиннее выпавшей длины пароля, лишние обязательные символы будут
отброшены обрезкой.

> Источник случайности — `random`, а не `secrets`. Для паролей от бирж и
> почт этого достаточно, но для ключей и seed-фраз используйте генераторы
> кошельков, где деривация идёт по BIP39.

## Результат

`result/password_generator.csv`, одна колонка `password`.

Файл **дописывается**, а не перезаписывается: заголовок пишется только
при создании файла. Пароли прошлых запусков остаются на месте, так что
файл со временем растёт — чистить его нужно вручную.

Лог запуска: `log/password_generator.log`. Каждый сгенерированный пароль
пишется в лог на уровне `DEBUG`.
