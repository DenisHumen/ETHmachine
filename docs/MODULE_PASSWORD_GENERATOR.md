# 🔐 Модуль Password Generator

## 📖 Описание

Модуль для генерации криптографически стойких паролей с настраиваемыми параметрами. Поддерживает различные наборы символов, обязательные символы и массовую генерацию с прогресс-баром.

## 🎯 Основные функции

### `get_charset()`

- Формирование набора символов для генерации
- Включение/исключение специальных символов
- Фильтрация нежелательных символов
- Валидация итогового charset

### `generate_password()`

- Генерация пароля случайной длины в заданном диапазоне
- Гарантия включения обязательных символов
- Перемешивание символов для randomness
- Соблюдение всех настроек безопасности

### `save_password(password)`

- Сохранение паролей в CSV формате
- Автоматическое создание заголовков
- Append режим для накопления данных
- Создание директории результатов

### `print_progress_bar(iteration, total, length)`

- Визуальный прогресс-бар для отслеживания
- Процентное отображение завершения
- Настраиваемая ширина индикатора
- Real-time обновление статуса

### `setup_password_generator_logging()`

- Настройка детального логирования
- Ротация логов по размеру (10 MB)
- Хранение логов в течение 7 дней
- Timestamp в имени файла

### `password_generator_menu()`

- Главная функция запуска генерации
- Обработка ошибок и исключений
- Логирование всего процесса
- Вывод статистики результатов

## ⚙️ Настройки генерации

```python
# config/modules/cfg_password.py
USE_SPECIAL_CHARACTERS = True      # Включить спец. символы (!@#$%^&*)
EXCLUDE_CHARACTERS = "0O1lI"       # Исключить похожие символы
USE_OF_SYMBOLS_IS_MANDATORY = "@"  # Обязательные символы в пароле
PASSWORD_LENGTH = [12, 16]         # Диапазон длины пароля
COUNT_GENERATED_PASSWORDS = 1000   # Количество паролей для генерации
```

## 🔣 Типы символов

### Базовый набор

- **Строчные буквы**: a-z (26 символов)
- **Заглавные буквы**: A-Z (26 символов)  
- **Цифры**: 0-9 (10 символов)

### Специальные символы

```text
!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~
```

### Исключаемые символы

По умолчанию исключаются визуально похожие:

- **0** (ноль) и **O** (буква O)
- **1** (единица), **l** (маленькая L), **I** (большая i)

## 📂 Результаты

- **Файл**: `result/password_generator.csv`
- **Формат**: CSV с заголовком "password"
- **Режим**: Append (добавление к существующему файлу)

### Пример результата

```csv
password
K7@mN2pQ8wX9
Rt5$bH3nM6@L

```

## 📊 Логирование

- **Основной лог**: `log/password_generator_YYYYMMDD_HHMMSS.log`
- **Уровень**: DEBUG (все операции)
- **Ротация**: 10 MB
- **Хранение**: 7 дней

### Структура логов

```text
2024-01-15 14:30:25 | INFO | Начинаем генерацию 1000 паролей
2024-01-15 14:30:25 | INFO | Параметры: длина [12, 16], спец. символы: True
2024-01-15 14:30:25 | DEBUG | Пароль сгенерирован: K7@mN2pQ8wX9
2024-01-15 14:30:30 | SUCCESS | Генерация паролей завершена. Создано: 1000 паролей
```

## 🔒 Безопасность

### Криптографическая стойкость

- **Энтропия**: 128+ бит для паролей длиной 12+ символов
- **Случайность**: Python `random` модуль (подходит для большинства случаев)
- **Перемешивание**: shuffle для дополнительной randomness

### Соответствие стандартам

- **NIST Guidelines**: соответствие рекомендациям по паролям
- **OWASP**: следование лучшим практикам безопасности
- **Entropy Calculation**: высокая энтропия за счет charset разнообразия

### Рекомендации

```python
# Для максимальной безопасности:
USE_SPECIAL_CHARACTERS = True
```

## 🛠️ Диагностика ошибок

### Типичные ошибки

1. **Пустой charset**
   ```
   Error: Charset is empty after exclusions
   Solution: Уменьшить количество исключаемых символов
   ```

2. **Недоступная директория**
   ```
   Error: Permission denied to create result directory
   Solution: Проверить права доступа к файловой системе
   ```

3. **Некорректные настройки длины**
   ```
   Error: Invalid password length range
   Solution: Убедиться что min_length <= max_length
   ```

## 📈 Статистика

### Энтропия паролей

- **12 символов**: ~78 бит энтропии
- **16 символов**: ~104 бит энтропии
- **20 символов**: ~130 бит энтропии

### Charset размеры

- **Только буквы+цифры**: 62 символа
- **С спец. символами**: ~95 символов
- **После исключений**: ~90 символов
