# ETHmachine

ETHmachine — мультифункциональный Python-инструмент для работы с Ethereum и EVM-совместимыми сетями.

## Возможности

- **Проверка балансов (modules/get_wallet_balance.py, get_wallet_balance_fast.py)**  
  Массовая проверка балансов кошельков в выбранной сети.  
  - Быстрый режим (через прокси, параллельно)
  - Медленный режим (без прокси, последовательно)

- **Суммирование балансов (modules/sum_balances.py)**  
  Подсчет общей суммы по всем кошелькам из файла результатов.

- **Проверка цены газа (modules/get_gas_price.py)**  
  Получение актуальной цены газа в выбранной сети.

- **Проверка количества транзакций (modules/get_transaction_count.py)**  
  Массовая проверка nonce (количества транзакций) по кошелькам.

- **Генерация кошельков (modules/wallet_generator.py)**  
  Генерация мнемоник, приватных ключей и адресов с верификацией.

- **Массовые переводы (modules/transefer_wallets_to_wallets.py)**  
  Отправка средств между кошельками через промежуточный кошелек с учетом комиссий и минимального остатка.

- **Работа с CEX (modules/cex/okx_withdraw.py)**  
  Вывод средств с биржи OKX на выбранный адрес.

- **Конвертация мнемоник (modules/mnemonic_to_privkey.py)**  
  Преобразование мнемонической фразы в приватный ключ и адрес.

- **Поддержка прокси (modules/proxy/...)**  
  Для обхода ограничений RPC и ускорения массовых операций.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DenisHumen/ETHmachine.git
   cd ETHmachine
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Заполните необходимые файлы в папке `data/`:
   - `walletss.txt` — список адресов или приватных ключей (по одному в строке).
   - `proxy.csv` — список прокси (опционально, для быстрого режима).
   - `cex_settings.py` — настройки для работы с OKX.

## Запуск

```bash
python main.py
```

Следуйте интерактивному меню.

## Структура проекта

- `main.py` — основной скрипт с меню.
- `modules/` — все вспомогательные модули:
  - `get_wallet_balance.py` — медленная проверка баланса.
  - `get_wallet_balance_fast.py` — быстрая проверка баланса через прокси.
  - `sum_balances.py` — суммирование балансов.
  - `get_gas_price.py` — получение цены газа.
  - `get_transaction_count.py` — проверка количества транзакций.
  - `wallet_generator.py` — генерация кошельков.
  - `transefer_wallets_to_wallets.py` — массовые переводы между кошельками.
  - `cex/okx_withdraw.py` — вывод с OKX.
  - `mnemonic_to_privkey.py` — конвертация мнемоник.
  - `proxy/` — вспомогательные скрипты для работы с прокси.
- `config/` — настройки потоков, RPC, параметры переводов.
- `data/` — входные данные (кошельки, прокси, настройки CEX).
- `result/` — результаты работы (балансы, транзакции и т.д.).
- `db/` — файлы прогресса для возобновления переводов.

## Поддерживаемые сети

## Важно

- Для массовых операций рекомендуется использовать прокси.
- Перед использованием убедитесь, что все настройки заполнены корректно.
- Для работы с OKX получите API-ключи и пропишите их в `data/cex_settings.py`.
