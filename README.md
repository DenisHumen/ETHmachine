## 📖 О проекте

ETHmachine — это инструмент для проверки балансов Ethereum кошельков, подсчета транзакций, анализа стоимости газа и многого другого. Поддерживаются как основные сети, так и тестовые. Скрипт предоставляет гибкие режимы работы: быстрый (с использованием прокси) и медленный (без прокси).

---

## 🛠️ Установка и настройка

1. Убедитесь, что у вас установлен Python 3.7+.
2. Установите зависимости:
   ```sh
   pip install -r requirements.txt
   ```
3. Подготовьте файлы:
   - `data/walletss.txt`: список адресов кошельков (по одному на строку).
   - `data/proxies.txt`: список прокси (для быстрого режима, формат `http://proxy.example.com:8080`).

---

## 🚀 Использование

### Запуск скрипта
Запустите основной файл:
```sh
python main.py
```

Или используйте бинарник (для стабильной версии):
```sh
./checker_linux
```

### Основные функции
1. **💲 Проверка балансов**:
   - Выберите сеть (например, Ethereum Mainnet, Sepolia, Polygon и др.).
   - Результаты сохраняются в `result/result.csv`.

2. **💰 Суммирование балансов**:
   - Суммируйте балансы из файла `result/result.csv`.

3. **⛽ Проверка стоимости газа**:
   - Узнайте текущую стоимость газа в выбранной сети.

4. **🔢 Подсчет транзакций**:
   - Проверьте количество транзакций для кошельков.

5. **🪙 Генерация кошельков**:
   - Создавайте до 10,000 новых кошельков.

6. **🏦 Работа с CEX**:
   - Проверка балансов и вывод средств через OKX (позже будут добалены другие биржи).

## ⚙️ Режимы работы

1. **🚀 Быстрый режим**:
   - Использует многопоточность и прокси.
   - Требуется файл `data/proxies.txt`.

2. **🐢 Медленный режим**:
   - Однопоточная проверка без прокси.
   - Подходит для небольших объемов данных.

## 📂 Формат выходных данных

### Балансы (`result/result.csv`):
```
address,balance,network
0x123...,0.5,Ethereum Mainnet
0x456...,1.2,Polygon
```

### Транзакции (`result/transaction_count_result.csv`):
```
address,transaction_count,network
0x123...,10,Ethereum Mainnet
0x456...,5,Polygon
```

## 🛡️ Важные замечания

- При обновлении проекта структура файлов может измениться. Сохраняйте свои данные заранее.
- Для быстрого режима рекомендуется использовать прокси в 2-3 раза больше, чем количество кошельков.
